# AlphaClip Forge

Crypto **Shorts / TikTok clip factory** for [Kevin Lance Murray](https://github.com/HEADWOPZ).
Ingest a YouTube, X, Loom, or local source → transcript → highlight score → ffmpeg cut → burned captions + CTA + disclaimer → **9:16 zip**.

v1 is a laptop tool. It does **not** grow virtual influencer faces, run a 24-channel farm, or auto-post to a marketplace.

## Architecture

```
source URL / file
        │
        ▼
   ingest (yt-dlp or copy)
        │
        ▼
   transcript (faster-whisper | whisper CLI | mock JSON)
        │
        ▼
   highlight scorer  +  preset (hooks / CTA / disclaimer)
        │
        ▼
   ffmpeg cut → 1080×1920 crop → ASS captions burned in
        │
        ▼
   zip (clips/*.mp4 + metadata.json)
        │
        └── optional schedule hook (Buffer / Late, dry-run without keys)
```

| Piece | Module |
| --- | --- |
| CLI | `alphaclip forge` / `serve` / `demo` / `doctor` |
| Web UI | FastAPI + static dark UI (`alphaclip serve`) |
| Presets | `trench-recap`, `protocol-explainer`, `wallet-security-tip` |
| Skills | `skills/alphaclip-hooks`, `skills/alphaclip-disclaimers` (also under `.claude/skills/`) |

CPU-only is the default path. GPU is optional and unused unless you install a Whisper extra and pick a larger model.

## Dependencies

System:

- **ffmpeg** + **ffprobe** (required to cut and burn captions)
- A caption font (Inter, Liberation Sans, or `ALPHACLIP_FONT`)

Python 3.11+ (see `pyproject.toml`). Remote ingest needs **yt-dlp**. Real speech-to-text needs one of:

| Engine | Install | Notes |
| --- | --- | --- |
| mock transcript | shipped `fixtures/demo_transcript.json` | CI / laptops / no network |
| [faster-whisper](https://github.com/SYSTRAN/faster-whisper) | `pip install 'alphaclip-forge[whisper]'` | Preferred. `tiny` / `base` are fine on CPU |
| OpenAI `whisper` CLI | `pip install openai-whisper` | Fallback if on `PATH` |

### Whisper model sizes (optional)

Set `ALPHACLIP_WHISPER_MODEL` or `--whisper-model`.

| Size | When to use |
| --- | --- |
| `tiny` (default) | Fastest CPU. Rough hooks. |
| `base` | Better accuracy, still OK on CPU for short sources. |
| `small` | Best CPU quality if you can wait. |
| `medium` / `large-v3` | Prefer a GPU. |

Mock mode never downloads weights.

## Install

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
# optional: pip install -e ".[whisper]"
alphaclip doctor
```

Copy `.env.example` if you want schedule keys later. The CLI reads process env; it does not require a dotenv file.

## Run

**Demo fixture (no network, no GPU, no Whisper):**

```bash
alphaclip demo
# or
alphaclip forge fixtures/demo.mp4 --preset trench-recap --mock-transcript
```

That writes a zip of captioned 1080×1920 clips plus `metadata.json` (titles, hooks, CTA, disclaimer, scores).

**Local file or remote URL:**

```bash
alphaclip forge ./talk.mp4 --preset protocol-explainer --whisper-model tiny
alphaclip forge --url 'https://www.youtube.com/watch?v=…' --preset wallet-security-tip
```

You must own or have a license to the source. yt-dlp will fail closed on private / blocked media.

**Web UI:**

```bash
alphaclip serve --host 127.0.0.1 --port 8080
```

Paste a URL, upload a file, or leave **Mock transcript** on to forge the bundled tape. Confirm rights, then download the zip.

**Hooks without an LLM:**

```bash
alphaclip hooks --preset trench-recap --text "Three liquidations cascaded on 40x."
```

Agent-facing copy lives in `skills/` (Claude Code also sees `.claude/skills/`).

**Schedule stub:**

```bash
alphaclip schedule --metadata var/jobs/<id>/metadata.json --provider buffer
```

Always dry-runs unless `BUFFER_ACCESS_TOKEN` + `BUFFER_PROFILE_ID` (or `LATE_API_KEY` + `LATE_ACCOUNT_ID`) are set **and** you pass `--live`. v1 will not auto-post by accident.

## Presets

| id | Use |
| --- | --- |
| `trench-recap` | Overnight tape: liquidations, runners, rugs |
| `protocol-explainer` | How a vault / AMM / oracle / restake flow works |
| `wallet-security-tip` | Drainers, approvals, seed phrases, hardware wallets |

Each preset owns keyword weights, hook/title templates, a CTA overlay, and a financial-content disclaimer that is burned into every frame.

## Fixtures

`fixtures/demo.mp4` is a 32s 1280×720 card-tape generated by `python scripts/make_fixture.py`.
`fixtures/demo_transcript.json` is the aligned mock transcript so CI and laptops do not need the network.

## Tests

```bash

```

Coverage includes highlight scoring, caption / ASS burn helpers, presets, the schedule dry-run, and an end-to-end mock forge that asserts at least one 1080×1920 clip inside the zip.
